\title{Rank--Depth Adaptive Block Matrix Products for Quantum Operator Learning}

\author{Molena Huynh}
\affiliation{Independent Researcher, Raleigh, North Carolina, USA}

\date{August 1, 2026}

\begin{abstract}
Learning a parameterized quantum operator from many correlated preparations
requires block products of the form
$B^{\mathsf T}f(A(\theta))B$ and their parameter derivatives.  Treating the
columns independently discards correlation, whereas using the complete block
can spend Hamiltonian applications on numerically redundant preparations.  We
introduce a preflight rank--depth rule that selects a truncated singular-value
factorization of $B$ and a block-Krylov depth before the first Hamiltonian
application.  The rule combines three deterministic ingredients: a uniform
spectral enclosure valid on a prescribed parameter box, an explicit bound for
the effect of probe compression on every loss-gradient component, and positive
Taylor majorants for the remaining matrix-function and Fr\'echet-derivative
tails.  In exact arithmetic, the resulting Euclidean bound certifies the full
gradient error; the implementation separately records loss of orthogonality.
Tests on four checksum-authenticated PARSEC density-functional-theory
Hamiltonians, of dimensions 769--19,896, select ranks five or six from an
eight-column block and depth 24 at tolerance $10^{-3}$.  This reduces the
Hamiltonian-vector equivalent count by 25--37.5 percent relative to an
uncompressed block at the same depth and by factors of 8--9.6 relative to
coordinatewise finite differences.  Paired CPU timings favor the proposed
method on three matrices by factors 1.36--2.04; on the largest matrix the
uncompressed block is 1 percent faster.  The calculation is a numerical
operator benchmark: the Hamiltonians are authentic, while the parameter
directions, preparations, and targets are reproducible constructed quantities.
\end{abstract}

\section{Introduction}

Matrix functions provide a compact description of quantum propagation,
thermal response, filtering, and spectral observables
\cite{higham2008,saad1992,hochbruck1997}.  A recurring inverse problem observes
several small matrices
\begin{equation}
 F_\ell(\theta)=B^{\mathsf T}f_\ell(A(\theta))B,
 \qquad \ell=1,\ldots,s,
 \label{eq:block-product}
\end{equation}
where $A(\theta)$ is too large to factor or diagonalize, $B\in\RR^{n\times b}$
contains preparations or probes, and $b\ll n$.  The loss depends on every
entry of every block product, so the derivative is not a collection of
unrelated scalar derivatives.

Krylov projection replaces the large matrix function by a function of a small
Hessenberg or tridiagonal matrix \cite{lanczos1950,saad1992,golub2010}.  Block
Krylov methods reuse one projected space for several right-hand sides and have
matrix-function error analyses tailored to that setting
\cite{gutknecht2007,xu2022}.  Fr\'echet derivatives can likewise be approximated
through block or tensorized Krylov spaces
\cite{kandolf2017,kandolf2021,kressner2019}.  More recently, Singh, Barros, and
Li derived a stable forward-only gradient approximation for scalar bilinear
forms of Hermitian matrix functions \cite{singh2026}.  Their result addresses
the differentiation bottleneck without backpropagating through Lanczos.

The present problem has a distinct resource question.  Correlated columns of
$B$ may have numerical rank $r<b$.  Reducing the block width lowers the cost of
every subsequent sparse matrix--matrix product, but it also perturbs the
observed block and its gradient.  Moreover, checking successive Krylov depths
after each extension can consume more time in reduced eigendecompositions and
direction projections than it saves in Hamiltonian applications.  Our initial
implementation exhibited precisely this behavior.  A useful algorithm must
therefore decide both rank and depth without repeatedly executing the large
operator.

We develop such a rule for the cosine response
$f_\ell(x)=\cos(t_\ell x)$ and real-symmetric affine families.  Its contributions
are as follows.

\begin{enumerate}
\item A row-sum construction gives a uniform, noniterative enclosure
$\norm{A(\theta)}_2\le\rho<1$ over a complete parameter box.  It avoids using an
unconverged extremal Ritz value as a certificate.
\item A probe-compression theorem bounds both the block response and its
Fr\'echet derivative after replacing $B$ by a truncated SVD $B_r$.
\item Polynomial exactness converts positive cosine tails into a gradient
certificate depending only on registered inputs.  A conservative residual
upper bound makes the certificate available before any Hamiltonian product.
\item A preflight algorithm chooses the least SVD rank within a compression
budget and the first Krylov depth satisfying the full gradient tolerance.  It
then executes one compressed block factorization.
\item An authenticated CPU study reports deterministic work, observed error,
certificate slack, all timing repetitions, and a negative timing result on the
largest matrix.
\end{enumerate}

The method is classical numerical linear algebra for a quantum inverse problem.
It does not claim a quantum computational advantage or infer chemical
parameters from experimental measurements.

\section{Block operator-learning objective}

Let
\begin{equation}
 A(\theta)=H_0+\sum_{j=1}^{p}\theta_jD_j,
 \qquad A(\theta)=A(\theta)^{\mathsf T},
 \label{eq:affine-family}
\end{equation}
and let the registered parameter domain be
$\ThetaBox=\{\theta:|\theta_j|\le a_j\}$.  For observed symmetric targets
$Y_\ell\in\RR^{b\times b}$, consider
\begin{equation}
 \Phi(\theta)=\frac{1}{2s}\sum_{\ell=1}^{s}
 \norm{F_\ell(\theta)-Y_\ell}_F^2,
 \label{eq:loss}
\end{equation}
with $F_\ell$ defined in Eq.~\eqref{eq:block-product}.  The $j$th gradient
component is
\begin{equation}
 g_j(\theta)=\frac{1}{s}\sum_{\ell=1}^{s}
 \ip{F_\ell(\theta)-Y_\ell}
 {B^{\mathsf T}\Lfrechet_{f_\ell}(A(\theta),D_j)B},
 \label{eq:gradient}
\end{equation}
where $\Lfrechet_f(A,D)$ denotes the Fr\'echet derivative of $f$ at $A$ in
direction $D$ \cite{higham2008,al-mohy2009}.  Equation~\eqref{eq:gradient}
contains $sb^2$ response entries but only one large operator family.

\subsection{Uniform parameter-box scaling}

The proof requires a spectral interval known before the Krylov calculation.
The following construction uses quantities that are exact for the stored sparse
matrix and diagonal directions.

\begin{lemma}[Uniform spectral enclosure]
\label{lem:box}
Suppose $H_0=H_0^{\mathsf T}$, $D_j=D_j^{\mathsf T}$, and
\begin{equation}
 \norm{H_0}_\infty+\sum_{j=1}^{p}a_j\norm{D_j}_2\le\rho.
 \label{eq:box-condition}
\end{equation}
Then $\norm{A(\theta)}_2\le\rho$ for every $\theta\in\ThetaBox$.
If each $D_j$ is diagonal, its norm in Eq.~\eqref{eq:box-condition} is the
largest absolute diagonal entry.
\end{lemma}

\begin{proof}
Symmetry gives
$\norm{H_0}_2\le\sqrt{\norm{H_0}_1\norm{H_0}_\infty}
=\norm{H_0}_\infty$.  Hence, for $\theta\in\ThetaBox$,
\begin{align}
 \norm{A(\theta)}_2
 &\le \norm{H_0}_2+\sum_{j=1}^{p}|\theta_j|\norm{D_j}_2 \\
 &\le \norm{H_0}_\infty+\sum_{j=1}^{p}a_j\norm{D_j}_2
 \le\rho.
\end{align}
For diagonal $D_j$, the spectral norm equals the maximum absolute diagonal
entry.
\end{proof}

Our benchmark scales the authenticated Hamiltonian so that
$\norm{H_0}_\infty=0.8$, uses $p=3$, $a_j=0.5$, and constructs diagonal
directions with norm at most $0.12$.  Thus $\rho\le0.98$ without an eigensolver.

\section{Rank--depth preflight method}

\subsection{Probe-block compression}

Let the thin SVD be
\begin{equation}
 B=U\Sigma W^{\mathsf T},\qquad
 B_r=U_r\Sigma_rW_r^{\mathsf T},
 \label{eq:probe-svd}
\end{equation}
and write $\delta_r=\norm{B-B_r}_F$.  The implementation forms a Krylov basis
from $C_r=U_r\Sigma_r$ and lifts each $r\times r$ projected product back to
$b\times b$ with $W_r$.  Consequently, the output retains its original shape.

\begin{theorem}[Probe-compression perturbation]
\label{thm:compression}
Let $A=A^{\mathsf T}$, $D=D^{\mathsf T}$, and
$\operatorname{spec}(A)\subset[-\rho,\rho]$.  Define
\begin{equation}
 \alpha_r=2\norm{B}_2\delta_r+\delta_r^2.
 \label{eq:alpha}
\end{equation}
For $f_t(x)=\cos(tx)$,
\begin{align}
 \norm{B^{\mathsf T}f_t(A)B-B_r^{\mathsf T}f_t(A)B_r}_F
 &\le\alpha_r, \label{eq:response-compression}\\
 \norm{B^{\mathsf T}\Lfrechet_{f_t}(A,D)B
 -B_r^{\mathsf T}\Lfrechet_{f_t}(A,D)B_r}_F
 &\le |t|\norm{D}_2\alpha_r.
 \label{eq:derivative-compression}
\end{align}
\end{theorem}

\begin{proof}
Put $E=B-B_r$.  Because $\norm{f_t(A)}_2\le1$,
\begin{align}
 &B^{\mathsf T}f_t(A)B-B_r^{\mathsf T}f_t(A)B_r \nonumber\\
 &\quad=E^{\mathsf T}f_t(A)B_r+B_r^{\mathsf T}f_t(A)E
 +E^{\mathsf T}f_t(A)E.
\end{align}
The Frobenius--spectral product inequalities give
$2\norm{B_r}_2\norm{E}_F+\norm{E}_F^2\le\alpha_r$.
For a symmetric argument, differentiate
$e^{it(A+sD)}$ at $s=0$ by the Duhamel formula.  Unitary invariance gives
$\norm{\Lfrechet_{e^{it(\cdot)}}(A,D)}_2\le |t|\norm{D}_2$; averaging the
$+t$ and $-t$ exponentials therefore gives
\begin{equation}
 \norm{\Lfrechet_{f_t}(A,D)}_2
 \le |t|\norm{D}_2.
\end{equation}
Repeating the expansion with $f_t(A)$ replaced by
$\Lfrechet_{f_t}(A,D)$ proves Eq.~\eqref{eq:derivative-compression}.
\end{proof}

Let $c_B=\norm{B}_2\norm{B}_F$ and
$c_r=\norm{B_r}_2\norm{B_r}_F$.  Applying
Theorem~\ref{thm:compression} to Eq.~\eqref{eq:gradient} gives the preflight
compression component
\begin{equation}
 \chi_{j,r}=\frac{\alpha_r\norm{D_j}_2}{s}
 \sum_{\ell=1}^{s}|t_\ell|
 \left(c_B+c_r+\norm{Y_\ell}_F\right).
 \label{eq:compression-gradient}
\end{equation}
This quantity requires only the SVD of $B$, target norms, and direction norms.

\subsection{Block Krylov projection}

For $m\ge2$, let
\begin{equation}
 \Krylov_m(A,C_r)=\operatorname{span}
 \{C_r,AC_r,\ldots,A^{m-1}C_r\},
\end{equation}
and let $V_m$ be an orthonormal basis, with
$T_m=V_m^{\mathsf T}AV_m$ and $\widehat C=V_m^{\mathsf T}C_r$.  The projected
block response is
\begin{equation}
 \Fhat_{\ell,m,r}=W_r\widehat C^{\mathsf T}
 \cos(t_\ell T_m)\widehat C W_r^{\mathsf T}.
 \label{eq:projected-response}
\end{equation}
For direction $D_j$, the derivative uses
$\widehat D_j=V_m^{\mathsf T}D_jV_m$ and the corresponding reduced Fr\'echet
derivative.  No $n\times n$ derivative is formed.

\begin{theorem}[Block polynomial exactness]
\label{thm:exactness}
For every polynomial $q$ of degree at most $m$,
\begin{align}
 C_r^{\mathsf T}q(A)C_r
 &=\widehat C^{\mathsf T}q(T_m)\widehat C,\label{eq:qexact}\\
 C_r^{\mathsf T}\Lfrechet_q(A,D)C_r
 &=\widehat C^{\mathsf T}
 \Lfrechet_q(T_m,V_m^{\mathsf T}DV_m)\widehat C.
 \label{eq:dqexact}
\end{align}
\end{theorem}

\begin{proof}
For $0\le k\le m-1$,
$A^kC_r=V_mT_m^k\widehat C$.  If $0\le k\le m$, choose
$u+v=k$ with $u,v\le m-1$.  Symmetry yields
\begin{equation}
 C_r^{\mathsf T}A^kC_r
 =(A^uC_r)^{\mathsf T}A^vC_r
 =\widehat C^{\mathsf T}T_m^k\widehat C.
\end{equation}
For a monomial $q(x)=x^k$,
\begin{equation}
 \Lfrechet_q(A,D)=\sum_{u=0}^{k-1}A^uDA^{k-1-u}.
 \label{eq:monomial-frechet}
\end{equation}
When $k\le m$, both powers in every summand are at most $m-1$; substituting
$A^uC_r=V_mT_m^u\widehat C$ on both sides of $D$ proves
Eq.~\eqref{eq:dqexact}.  Linearity completes both statements.
\end{proof}

\subsection{A preflight gradient certificate}

For degree $m$ and radius $\rho$, define the positive tails
\begin{align}
 R_m^{(0)}(t,\rho)
 &=\sum_{\substack{\nu>m\\ \nu\ {\rm even}}}
 \frac{|t|^\nu\rho^\nu}{\nu!},\label{eq:R0}\\
 R_m^{(1)}(t,\rho)
 &=\sum_{\substack{\nu>m\\ \nu\ {\rm even}}}
 \frac{\nu|t|^\nu\rho^{\nu-1}}{\nu!}.
 \label{eq:R1}
\end{align}
The code bounds each series by its first term divided by one minus the largest
subsequent term ratio and converts the high-precision result to binary64 with
upward rounding.

\begin{theorem}[Rank--depth preflight certificate]
\label{thm:certificate}
Assume Lemma~\ref{lem:box}.  Let $\widehat g_{m,r}$ be the gradient obtained from
$B_r$ and the projected products in Eq.~\eqref{eq:projected-response}.  Define
\begin{align}
 \kappa_{j,m,r}=\frac{1}{s}\sum_{\ell=1}^{s}
 \bigl[&2c_rR_m^{(0)}(t_\ell,\rho)\,
 c_r|t_\ell|\norm{D_j}_2 \nonumber\\
 &+(c_r+\norm{Y_\ell}_F)
 2c_r\norm{D_j}_2R_m^{(1)}(t_\ell,\rho)\bigr],
 \label{eq:kappa}
\end{align}
and $\eta_{j,m,r}=\chi_{j,r}+\kappa_{j,m,r}$.  Then
\begin{equation}
 \norm{g-\widehat g_{m,r}}_2
 \le\left(\sum_{j=1}^{p}\eta_{j,m,r}^2\right)^{1/2}.
 \label{eq:certificate}
\end{equation}
Every quantity on the right is available before applying $A(\theta)$.
\end{theorem}

\begin{proof}
Let $c_m$ be the degree-$m$ Taylor polynomial of $f_t$.  Theorem
\ref{thm:exactness} cancels its full and projected contributions.  The remaining
tails and $\norm{T_m}_2\le\norm{A}_2\le\rho$ give
\begin{align}
 \norm{B_r^{\mathsf T}f_t(A)B_r-\widehat F_{t,m,r}}_F
 &\le2c_rR_m^{(0)}(t,\rho),\label{eq:tail-response}\\
 \norm{B_r^{\mathsf T}\Lfrechet_{f_t}(A,D_j)B_r
 -\widehat J_{j,t,m,r}}_F
 &\le2c_r\norm{D_j}_2R_m^{(1)}(t,\rho).
 \label{eq:tail-derivative}
\end{align}
Furthermore,
$\norm{B_r^{\mathsf T}\Lfrechet_{f_t}(A,D_j)B_r}_F
\le c_r|t|\norm{D_j}_2$, and
$\norm{\widehat F_{t,m,r}-Y}_F\le c_r+\norm{Y}_F$.
Insert and subtract the compressed exact gradient in
Eq.~\eqref{eq:gradient}.  Theorem~\ref{thm:compression} and Cauchy--Schwarz give
$\chi_{j,r}$ for the first difference.  Equations
\eqref{eq:tail-response}--\eqref{eq:tail-derivative} give
$\kappa_{j,m,r}$ for the second.  The triangle inequality gives the component
bound, and summing its squares proves Eq.~\eqref{eq:certificate}.
\end{proof}

\begin{corollary}[First-feasible resource rule]
\label{cor:rule}
Fix $0<\gamma<1$, tolerance $\varepsilon$, and increasing depth grid
$\mathcal M$.  Choose the smallest $r$ satisfying
$\norm{\chi_r}_2\le\gamma\varepsilon$, then the first $m\in\mathcal M$ satisfying
$\norm{\eta_{m,r}}_2\le\varepsilon$.  The gradient returned by one rank-$r$,
depth-$m$ factorization satisfies
$\norm{g-\widehat g_{m,r}}_2\le\varepsilon$ in exact arithmetic.
\end{corollary}

The implementation uses $\gamma=0.2$.  Finite precision is audited by
$\norm{V_m^{\mathsf T}V_m-I}_2$; the theorem is not presented as an interval
arithmetic result for the computed basis.

\begin{center}
\fbox{\begin{minipage}{0.94\textwidth}
\textbf{Preflight rank--depth block product.}
(1) Authenticate the sparse matrix and construct a parameter box satisfying
Lemma~\ref{lem:box}.  (2) Compute one thin SVD of $B$ and choose the first rank
$r$ whose compression-gradient bound uses at most $\gamma\varepsilon$.
(3) Evaluate Eq.~\eqref{eq:certificate} over the registered depth grid and
select the first feasible $m$.  These three steps require no Hamiltonian
application.  (4) Build one fully reorthogonalized basis
$V_m$ from $C_r=U_r\Sigma_r$.  (5) Project $A$ and every $D_j$, evaluate the
reduced cosine and Loewner Fr\'echet matrices, lift with $W_r$, and return the
loss, gradient, certificate, action ledger, and orthogonality audit.
\end{minipage}}
\end{center}

\subsection{Computational contract}

Let $\mathcal C_A(n,r)$ denote the cost of one matrix-free application of $A$
to $r$ columns.  The implemented fully reorthogonalized calculation costs
\begin{equation}
 O\!\left(m\mathcal C_A(n,r)+nm^2r^2
 +pnm^2r^2+sp(mr)^3\right),
 \label{eq:complexity}
\end{equation}
where the terms respectively represent operator products, reorthogonalization,
diagonal-direction projection, and the present reduced Fr\'echet implementation.
The dominant basis memory is $O(nmr)$; no dense $n\times n$ matrix is formed.
The deterministic Hamiltonian-vector equivalent count is $mr$, compared with
$mb$ for an uncompressed block at the same depth and $2pmb$ for coordinatewise
central differences.  Equation~\eqref{eq:complexity} makes no claim that a
smaller $r$ must reduce wall time on every sparse kernel.

\section{Limitations and scope}

The theorem concerns real-symmetric matrices and cosine responses.  Complex
Hermitian matrices require conjugate transposes but no conceptual change;
nonnormal generators require a numerical-range or logarithmic-norm analysis.
The Taylor majorant is intentionally simple and becomes severely conservative
after the actual error reaches roundoff.  Spectrum-adapted polynomial or
contour bounds \cite{chen2022,xu2022,simunec2023} may reduce depth, but combining
them with probe compression requires a separate proof.

The probe SVD costs $O(nb^2)$ and is useful only when $b$ is moderate and its
columns are correlated.  An orthogonal or slowly decaying probe block can force
$r=b$, in which case the method reduces to an ordinary full-block calculation.
The Si5H12 timing demonstrates that a strict action reduction need not translate
to an end-to-end CPU speedup.

Finally, the PARSEC inputs are authentic electronic-structure matrices, but the
affine directions, probes, and targets are constructed numerical quantities.
The study validates a matrix-function learning kernel, not an experimental
Hamiltonian-identification pipeline.  Device data would introduce sampling
noise, model discrepancy, and likelihood design beyond the deterministic error
treated here \cite{shabani2011,wiebe2014,bairey2019}.

The accompanying repository contains the downloader, pinned archive digests,
installable CPU implementation, unit tests, complete timing arrays, locked JSON

\section{Conclusion}

Correlated quantum preparations create a block resource that should be managed
before Krylov propagation, not after it.  The proposed method combines an SVD
tail, a uniform parameter-box enclosure, polynomial exactness, and positive
cosine tails into a gradient certificate available without Hamiltonian
applications.  This preflight calculation selects both block rank and Krylov
depth and then executes one projected gradient evaluation.  The authenticated
study establishes an exact work reduction and a conditional CPU benefit, while
retaining the largest-matrix timing exception and the considerable slack of the
certificate.  These boundaries are part of the result: block compression is a
certified resource option, not a universal speedup theorem.

\section{Geometric evaluation of the tails}

Let $q$ be the first even integer larger than $m$ and put
$z=|t|\rho$.  Consecutive terms of $R_m^{(0)}$ satisfy
\begin{equation}
 \frac{z^{\nu+2}/(\nu+2)!}{z^\nu/\nu!}
 =\frac{z^2}{(\nu+1)(\nu+2)}
 \le\frac{z^2}{(q+1)(q+2)}=\zeta_0.
\end{equation}
When $\zeta_0<1$,
\begin{equation}
 R_m^{(0)}(t,\rho)
 \le \frac{z^q}{q!}\frac{1}{1-\zeta_0}.
\end{equation}
For derivative terms,
\begin{equation}
 \frac{(\nu+2)|t|^{\nu+2}\rho^{\nu+1}/(\nu+2)!}
 {\nu|t|^\nu\rho^{\nu-1}/\nu!}
 =\frac{z^2}{\nu(\nu+1)}
 \le\frac{z^2}{q(q+1)}=\zeta_1,
\end{equation}
so
\begin{equation}
 R_m^{(1)}(t,\rho)
 \le\frac{q|t|^q\rho^{q-1}}{q!}\frac{1}{1-\zeta_1}.
\end{equation}
If either ratio is at least one, that candidate depth is declared infeasible and
the preflight scan advances.  The implementation uses 80-digit decimal
arithmetic for these expressions and rounds the binary64 conversion toward
$+\infty$.

\section{Reference and finite-difference checks}

The depth reference is not used by the stopping rule.  It appears only in the
post hoc error plots and tables.  For each matrix, targets are recomputed at
depths 26 and 28 with the full eight-column block.  The same comparison is made
